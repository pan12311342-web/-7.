# Практична робота №7 — мультимодальний аналіз рахунків

Застосунок: FastAPI + Pillow + OpenAI-compatible API.

## Запуск
1. Створіть віртуальне середовище.
2. Встановіть залежності: `pip install -r requirements.txt`
3. Скопіюйте `.env.example` у `.env` і заповніть ключ/API.
4. Запустіть: `uvicorn app.main:app --reload`
5. Відкрийте http://127.0.0.1:8000

Зображення рахунку завантажується через веб-форму. Конвеєр:
підготовка → мультимодальна модель → схема → програмні правила → auto/review/reject.

У `samples/own/` можна покласти власні вигадані рахунки.
