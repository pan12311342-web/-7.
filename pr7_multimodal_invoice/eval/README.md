# Оцінювання

Для кожного зразка зафіксувати:
- правильне значення;
- вилучене значення;
- правильно / помилка / пропуск / вигадка;
- правила, які спрацювали;
- очікуване та фактичне рішення;
- тихі помилки: неправильне значення, яке пройшло всі правила й отримало auto.

Після першого прогону змінити лише один параметр (наприклад, MAX_IMAGE_SIDE 800 → 1600) і повторити оцінювання.
